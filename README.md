# MC3 Bridge

Modern Combat 3: Fallen Nation 1.0.1 (Gameloft, только 32-бит) на 64-битном Android-телефоне: игра исполняется в
qemu-user внутри APK, её вызовы OpenGL ES уходят на GPU телефона. Альфа: меню и кампания, 60 кадров/с на OnePlus 13s.

Файлы игры в комплект не входят. Состояние, устройство и список недоделанного — в [PROJECT_STATE.md](PROJECT_STATE.md),
как делался перенос — в [docs/PORTING_GUIDE.md](docs/PORTING_GUIDE.md).

```sh
tools/build_install.sh noinstall   # порт + port/MC3-Bridge-debug.apk
tools/push_data.sh                 # APK игры 1.0.1 и распакованный кэш на телефон, папки открыты приложению
tools/launch.sh install            # установить и запустить
tools/pull_log.sh                  # лог -> logs/phone.log
tools/make_release.sh              # release/<версия>/: APK с release-ключом, исходники, INSTALL.txt, SHA256SUMS
```

## Файлы игры

Нужны два файла: APK игры **1.0.1** (`com.gameloft.android.GAND.GloftM3HP`) и кэш к нему — zip-архив
`com.gameloft.android.GAND.GloftM3HP.zip` (внутри `files/data/DATA_1…DATA_4_4` и плоские файлы) или уже распакованная
папка `com.gameloft.android.GAND.GloftM3HP`. Оба кладутся в папку приложения как есть, архив приложение распакует само.
Подробно: `tools/release_install.txt` (в релизе — `INSTALL.txt`).

**Папка BridgeGames.** С доступом ко всем файлам она основная: из `Android/data/com.jamescrumble.mc3/files/` туда сами
переезжают все файлы (APK, кэш, настройки, лог). Читаются обе папки, без доступа всё работает с папкой в `Android/data`.
Как это устроено: [docs/STORAGE.md](docs/STORAGE.md).

Сохранения игра пишет в свою приватную папку (`/data/data/<пакет игры>`), порт отображает её в приватную папку
приложения (`files/game/saves`): удаление приложения стирает прогресс, обновление — нет.

## Версии игры

| Версия | Пакет | Данные | Поддержка |
|---|---|---|---|
| 1.0.1 | `GAND.GloftM3HP` (versionCode 101) | кэш: `files/data/DATA_*` + плоские файлы | да |
| 1.1.x (1.1.6b, 1.1.7g) | `ANMP.GloftM3HM` | OBB `main.1120` + `patch.11428` | нет, другие точки входа и другой кэш |

В настройках перед игрой сверху написано, какая версия найдена.

## Настройки

В настройках перед игрой (значения хранятся в `settings.txt`):

| Настройка | Ключ | Что делает |
|---|---|---|
| Разрешение рендера | `RENDER_HEIGHT` | 480 / 540 / 720 по высоте, ширина по пропорциям экрана |
| Качество графики | `MC3_GENERATION` | Низкое / Среднее / Высокое / Максимум: что отвечают `useGeneration0/1/2` из Java игры (по умолчанию Максимум — так игра решает для незнакомого ей телефона) |
| Лимит кадров | `FPS_LIMIT` | 30 / 60 / 90 / 120 |
| Бесконечные деньги (эксперимент) | `MC3_MONEY_INFINITE` | Синие кредиты показываются как 9 999 999, покупки ничего не списывают; настоящий баланс не трогается и растёт от заработанного |
| Задать кредиты (эксперимент) | `MC3_MONEY_RESTORE` | Одноразово: через несколько секунд после загрузки профиля синие кредиты становятся этой суммой, затем значение стирается; при бесконечных деньгах не действует |

Деньги правятся по смещениям в библиотеке 1.0.1 (она без имён функций), перед правкой код сверяется слово в слово.
Золото (правый верхний угол) не меняется: в профиле его нет, вероятно, оно серверное.

## Что не работает

- Ролики (логотип Gameloft, брифинги миссий) не проигрываются: плеера нет, игре сразу сообщается, что ролик закончился.
- Сеть, мультиплеер, магазин за реальные деньги: игра работает в своём режиме «нет соединения».
