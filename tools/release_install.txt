Modern Combat 3 Bridge - установка
=============================

Modern Combat 3: Fallen Nation (Gameloft, только 32-бит) на 64-битном телефоне через qemu-user и проброс GLES на GPU.
Поддержана версия 1.0.1 (пакет com.gameloft.android.GAND.GloftM3HP). Файлы игры в комплект не входят:
нужны ваш APK версии 1.0.1 и кэш к ней. Версии 1.1.x (com.gameloft.android.ANMP.GloftM3HM, кэш в .obb) не подходят.

1. Установить MC3-Bridge-<версия>.apk (приложение "Modern Combat 3", пакет com.jamescrumble.mc3).

2. Запустить приложение и разрешить доступ ко всем файлам (приложение предложит само). Оно создаст папку

   /sdcard/BridgeGames/com.jamescrumble.mc3/

   Положить в неё файлы как есть (по кабелю с компьютера или файловым менеджером).
   Подойдёт и старая папка /sdcard/Android/data/com.jamescrumble.mc3/files/ : читаются обе, а при выданном
   доступе всё из неё переносится в BridgeGames само. Без доступа приложение работает с папкой в Android/data.

       <оригинальный APK игры 1.0.1>.apk          (не устанавливать, просто файлом)
       <zip-архив с кэшем игры>.zip               (не распаковывать)

   Имена файлов не важны, важны расширения. Архив нужен именно zip; приложение распакует его само
   при первом запуске игры (около 1,7 ГБ, несколько минут). Подходит:
     - com.gameloft.android.GAND.GloftM3HP.zip (внутри папка com.gameloft.android.GAND.GloftM3HP/files);
     - архив, внутри которого лежит такой zip, например "Modern Combat 3 HD v1.0.1 Remastered.zip".
       Если в нём есть и APK игры, отдельный APK класть не нужно: приложение возьмёт его из архива.
   После распаковки архив можно удалить.

   Вместо архива можно положить в ту же папку уже распакованную папку com.gameloft.android.GAND.GloftM3HP
   (внутри files/ лежат data/DATA_1 ... DATA_4_4 и остальные файлы). Если копировали её по adb, откройте папки приложению:
       adb shell "find /sdcard/BridgeGames/com.jamescrumble.mc3 -type d -exec chmod 2777 {} +"

3. Открыть приложение: сначала появятся настройки (разрешение, качество графики, лимит кадров, деньги, звук),
   кнопка "Играть" запускает игру. Первый запуск дольше: распаковывается sysroot (~100 МБ).

Ролики (логотип, брифинги перед миссиями) не показываются - плеера нет, игра идёт сразу дальше.
Сохранения лежат в приватной папке приложения: удаление приложения стирает прогресс, обновление - нет.

Исходники - MC3-Bridge-<версия>-src.zip (сборка описана в README.md).
Контрольные суммы - SHA256SUMS.
